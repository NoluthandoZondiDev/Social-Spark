      Social Spark is designed to provide a streamlined platform for connecting users through interactive features.

      and showcase creativity in a digital environment.
    </p>

  <section>
    <h2>2. Design Considerations</h2>
    <ul>
      <li><strong>User Experience (UX):</strong> Clean interface with intuitive navigation to minimize learning curve.</li>
      <li><strong>Scalability:</strong> Modular code structure to support future feature expansion.</li>
      <li><strong>Cross‑Platform Access:</strong> Built with web technologies (HTML, CSS, JS) so it can run directly in browsers like Edge or Chrome.</li>
      <li><strong>Performance:</strong> Lightweight assets and optimized scripts to ensure fast load times.</li>
      <li><strong>Security:</strong> GitHub integration ensures version control and transparency in code changes.</li>
    </ul>
  </section>

  <section>
    <h2>3. Utilisation of GitHub & GitHub Actions</h2>
    <ul>
      <li><strong>Version Control:</strong> All project files are stored in their native folder structure (no ZIP compression), making collaboration easier.</li>
      <li><strong>Continuous Integration (CI):</strong> GitHub Actions automate testing and deployment, ensuring code quality with every commit.</li>
      <li><strong>Documentation:</strong> README and project notes are maintained directly in the repository for clarity.</li>
      <li><strong>Deployment:</strong> GitHub Pages can be enabled to serve the app as a live browser‑ready site.</li>
    </ul>
  </section>
